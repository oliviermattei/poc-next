# killer-saas boilerplate

Un boilerplate SaaS modulaire, vendu à quelqu'un qui en fait son propre produit.
Deux publics se croisent dans ce dépôt, et chacun a sa propre documentation.

## Publics

**Propriétaire du projet**:
La personne qui a acheté le boilerplate et construit son SaaS dessus ; elle connaît les bases sans connaître le système, et se fait souvent aider d'un assistant IA.
_Avoid_: acheteur, utilisateur, développeur, client

**Client**:
Une personne qui utilise le SaaS du propriétaire du projet une fois celui-ci en ligne.
_Avoid_: utilisateur final, end user

## Documentation

**Guide**:
La documentation du boilerplate, destinée au propriétaire du projet : ce qui existe, comment le configurer, l'activer et le déployer.
_Avoid_: doc du boilerplate, docs, documentation

**Documentation produit**:
La documentation que le propriétaire du projet écrit pour ses clients, servie sous `/docs` par le module `docs`.
_Avoid_: docs, guide
