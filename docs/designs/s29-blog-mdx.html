Un test vert qui ne vérifie rien

Comment un prédicat satisfait par un seul module devient un nom écrit en dur.

OMOlivier Mattei·28 février 2026 ingénieriecoulisses
Zone non couverte par le design system. Le corps rendu du MDX — titres internes, paragraphes, listes, citations, images, blocs de code — n'a pas d'échelle typographique déclarée. Seul mono anticipe le code, « pour la documentation (s30) et le changelog (s31) ». Manque n°1 du document de design : à trancher avant l'exécution, et il sert les trois stories.

Le prédicat sélectionnait le premier module activé, hors socle, qui déclarait à la fois des routes, une entrée de navigation et une table. Écrit ainsi pour ne nommer personne.

Un seul module du dépôt le satisfaisait. Le prédicat le nommait donc, sans que personne puisse le voir.
