Un module déclare un contrat typé et vit dans packages/modules/<nom>, avec ses quatre couches.

Les quatre couches

Le domaine ne connaît ni framework, ni ORM, ni SDK. L'application porte les cas d'usage et les ports.

  • domain/ — les règles métier pures
  • application/ — les cas d'usage
  • infrastructure/ et presentation/ — jamais l'un l'autre

La règle que le lint tient

La frontière est vérifiée par une commande, pas par une relecture.

Générer plutôt que deviner

Produire un squelette à la main est un signal d'alerte :

npx ks scaffold mon-module
